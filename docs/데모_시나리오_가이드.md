# 데모 시나리오 가이드 (promptune-portfolio 전용)

promptune-portfolio(목업/데모 사이트)는 실제 ai-service를 호출하지 않고,
미리 준비된 질문/답변 시나리오로 채팅에 응답할 수 있다. 이 문서는 그 시나리오를
팀에서 직접 추가하는 방법을 설명한다.

> **`docs/MOCK_GUIDE.md`와는 다른 개념이다.** 그 문서의 "mock"은 "나중에 실제
> 모델로 교체할 임시 구현"을 말하고, 여기서 말하는 "데모(demo)"는
> promptune-portfolio 사이트에서 계속 쓸, 사람이 직접 작성한 고정 답변이다.
> 두 개를 헷갈리지 않도록 일부러 클래스/설정 이름을 mock이 아닌 demo로 지었다.

---

## 켜는 방법

Render의 **promptune-portfolio(백엔드)** 서비스 Environment 탭에서
`AI_DEMO_ENABLED=true`를 설정한다. (`promptune`(실제 운영) 서비스에는 절대
설정하지 않는다.)

켜지면 `AiServiceClient`의 `diagnose`/`suggest`/`retrievalExecute`/`generate`/
`validate` 5개 메서드가 `AI_SERVICE_URL` 호출 없이, 아래에서 설명하는
`demo-scenarios.json`으로 즉시 응답한다. `AI_SERVICE_URL`은 데모 모드에서는
아예 안 쓰이므로 비워둬도 된다.

---

## 시나리오 추가하는 방법

`backend/src/main/resources/demo-scenarios.json` 파일 하나에 시나리오
배열이 들어있다. 새 질문 세트를 하나 추가하려면, 이 배열에 항목을 하나
더 넣으면 된다(기존 이강인 예시 항목은 형식 참고용으로 남겨뒀다).

```json
{
  "matchQuestions": [
    "예상되는 질문 표현 1",
    "예상되는 질문 표현 2 (사람들이 다르게 물어볼 만한 문장들을 최대한 여러 개)"
  ],
  "diagnose": {
    "missing": {},
    "taskType": "chat",
    "typos": [],
    "needsInternalDocs": false
  },
  "suggestions": [],
  "webResults": [
    { "title": "근거 자료 제목", "url": "https://...", "content": "근거 자료 내용 요약" }
  ],
  "generatedAnswer": "채팅창에 그대로 보여줄 최종 답변 텍스트."
}
```

- **matchQuestions**: 사용자가 실제로 입력할 만한 질문들을 여러 표현으로
  적어둔다. 사용자가 입력한 문장과 글자 단위로 비교해 가장 비슷한 시나리오를
  찾으므로(정확히 똑같은 문장일 필요 없음), 같은 질문이라도 여러 방식으로
  물어볼 수 있게 3~5개 정도 다양하게 적어두는 게 좋다.
- **diagnose**: 보통은 예시처럼 비워둬도 된다(`missing: {}`, `typos: []`).
  일부러 "누락된 요소가 있는 질문"을 보여주고 싶은 시나리오라면
  `missing`에 `{"AUDIENCE": 1}`처럼 8요소 이름과 1(누락)/0(있음)을 채우면 된다.
- **suggestions**: 진단 화면에서 추천 문구를 보여주고 싶을 때만 채운다.
  안 쓰면 빈 배열로 둔다.
- **webResults**: 답변 아래 "근거 자료"로 표시할 목록. 실제로 존재하는
  출처(기사, 위키 등)의 제목/URL/요약을 적는다.
- **generatedAnswer**: 채팅창에 그대로 노출되는 최종 답변. 실제 서비스처럼
  자연스러운 문장으로 작성한다.

파일을 수정한 뒤 별도 코드 수정 없이 그대로 배포하면 새 시나리오가 바로
반영된다(Java 코드는 건드릴 필요 없음).

## 매칭이 안 될 때 (fallback)

사용자가 입력한 문장이 어떤 시나리오와도 충분히 비슷하지 않으면, 아래처럼
"준비된 질문에만 답할 수 있다"는 안내 답변으로 대체된다.

> 이 데모는 미리 준비된 질문에 대해서만 답변할 수 있어요. 다른 질문도
> 궁금하시다면 담당 팀에 문의해 주세요.

특정 질문이 계속 매칭 안 되는 것 같으면, 그 시나리오의 `matchQuestions`에
사용자가 실제로 입력한 표현을 그대로 추가하면 다음부터 잡힌다.

## 관련 파일

- `backend/src/main/resources/demo-scenarios.json` — 시나리오 데이터(팀이 직접 수정)
- `backend/src/main/java/com/promptune/service/DemoScenario.java` — 시나리오 항목 하나의 데이터 형태(JSON 스키마)
- `backend/src/main/java/com/promptune/service/DemoScenarioService.java` — 질문 매칭 로직(보통 수정할 필요 없음)
- `backend/src/main/java/com/promptune/service/AiServiceClient.java` — `ai.demo.enabled`(=`AI_DEMO_ENABLED`)가 켜졌을 때 위 시나리오로 응답을 대체하는 부분
